1. Objet

Vente d'un code d'accès numérique au jeu de piste « Pétrocores – Saint-Geniès » (application web), joué en autonomie dans l'espace public du village.

2. Prix

15 € par code. TVA non applicable, art. 293 B du CGI.

Paiement par carte via SumUp. La vente est conclue lorsque le paiement est accepté.

Le code s'affiche immédiatement après le paiement et est envoyé à l'adresse email indiquée. Le code est utilisable dans les 12 mois suivant l'achat. Il s'active lors de sa première utilisation sur place et reste valable jusqu'à minuit (heure de Paris) le jour de l'activation, sur 2 téléphones au maximum. Il ouvre les trois quêtes.

En cochant la case prévue avant le paiement, le client demande la fourniture immédiate du code et renonce à son droit de rétractation.

Si le code ne fonctionne pas pour une raison qui nous est imputable, contactez contact@escape-game-dordogne.fr : nous corrigeons, remplaçons le code ou remboursons.
